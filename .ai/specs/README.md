# Specyfikacje (SDD)

- Nazwa pliku: `YYYY-MM-DD-slug.md` (data utworzenia, slug kebab-case, np. `2026-10-25-mentor-booking-flow.md`).
- `.ai/specs/` – aktywne specyfikacje (do zrobienia / w toku).
- `.ai/specs/implemented/` – zaimplementowane w całości (przenieś plik po zakończeniu i weryfikacji).
- `.ai/specs/archive/` – porzucone lub zastąpione (dopisz na górze pliku powód i link do następcy).

Zalecana struktura specyfikacji: Cel · Zakres / poza zakresem · Wymagania · Kryteria akceptacji · Plan implementacji (kroki) · Ryzyka · Status.
