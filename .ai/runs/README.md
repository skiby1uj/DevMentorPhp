# Logi przebiegów AI

Jeden plik na autonomiczny przebieg: `YYYY-MM-DD-slug.md` (przy kilku w ciągu dnia – unikalny slug).
Szablon:

```
# <slug> – <krótki opis>
- Data / godzina: ...
- Model/agent: ...
- Spec: .ai/specs/<plik> (lub "brak")
- Cel:
## Przebieg (kroki, kluczowe decyzje)
## Zmienione pliki
## Weryfikacja (komendy, wyniki testów – także nieudane)
## Wynik / status (done | partial | blocked) i otwarte kwestie
## Lessons (linki do .ai/lessons/..., jeśli powstały)
```
